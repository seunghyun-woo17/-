# 03. qr.js — QR 코드 생성 엔진

**경로**: `js/qr.js` (77줄, 전체가 하나의 IIFE)
**역할**: 외부 CDN 없이 브라우저에서 QR 코드 이미지(canvas → PNG dataURL)를 생성하는 순수 JS 구현
**스펙**: Reed-Solomon 에러정정, 마스크 패턴 8종 중 페널티 최소값 자동 선택, Byte Mode(UTF-8)

---

## 공개 API

| 함수 | 줄 | 설명 |
|---|---|---|
| `global.renderQRTo(containerId, text, pixelSize)` | 53 | 지정한 `containerId` 엘리먼트 내부에 QR `<img>`를 렌더링하고 dataURL을 반환. 인코딩 실패 시 에러 박스를 표시 |

---

## 내부 구현 (수정 시 주의 — 일반적인 기능 추가에는 건드릴 필요 없음)

| 항목 | 줄 | 설명 |
|---|---|---|
| `gfMul`/`gfExp`/`getECPoly`/`rsEncode` | 14-17 | GF(256) 갈루아 필드 연산 + Reed-Solomon 에러정정 코드 생성 |
| `bchDigit`/`bchTypeInfo`/`MASK[8]` | 20-22 | 포맷 정보 BCH 코드, 마스크 패턴 8종 |
| `buildMatrix(ver, data8bits, maskId)` | 24 | 파인더/타이밍/정렬 패턴 + 데이터 비트 배치 → QR 매트릭스 생성 |
| `encodeText(text, ver)` | 39 | 텍스트 → Byte Mode 비트스트림 → 데이터/EC 코드워드 블록 인터리빙 |
| `cwToBits(cw)` | 51 | 코드워드 배열 → 비트 배열 |
