# 01. db.js — DB 스키마 + localStorage 레이어

**경로**: `js/db.js`
**역할**: localStorage 기반 데이터베이스 레이어. 모든 phase*.js가 `DB` 객체를 통해 데이터에 접근.
**★ 서버 전환 시**: 이 파일만 `js/api.js`로 교체하면 나머지 phase*.js는 수정 불필요 (db.js 단일 교체 전략)

---

## 2. 초기화 / 저장 / 리셋

| 함수 | 줄 | 설명 |
|---|---|---|
| `(function initDB(){...})()` | 63 | localStorage → `DB` 로드. item_name 누락된 기존 inventory 레코드 보정. 업체 DB가 비어있으면 기본 업체 1건 시드 |
| `dbSave(key)` | 93 | `DB[key]`를 `localStorage['avikus_'+key]`에 저장. 실패 시 `notify(...,'err')` |
| `dbReset()` | 103 | confirm 후 전체 테이블 초기화 + localStorage 삭제 + `refreshAllViews()` |

## 4. QR 페이로드 (avikus_system_report.html Section 3 명세)

| 함수 | 줄 | 설명 |
|---|---|---|
| `buildPOQRPayload(po, lines)` | 136 | `TYPE:PO\|ID:{po_id}\|REF:{po_ref_no}\|VND:{vnd}\|DUE:{due}\|VESSEL:{vessel}\|EM:{email}\|ITEMS:{code}:{qty},...` |

> QR은 "데이터 컨테이너"가 아니라 "조회 키"입니다 — 제품 QR의 `MC`(mc_code)로 `DB.inventory`를 조회합니다.
