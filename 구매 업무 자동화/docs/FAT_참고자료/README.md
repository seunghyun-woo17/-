# FAT 참고자료 (현업 엑셀 등)

이 폴더에 **선급 FAT 일정 · Comment 관리 엑셀** 등 현업에서 쓰는 자료를 넣어주세요.
phase-fat.js(QC FAT 관리)의 데이터 모델·상태·화면을 실제 업무에 맞게 정렬하는 데 사용합니다.

## 넣어주실 때 참고
- `.xlsx` 파일을 그대로 넣어주셔도 됩니다. **다만 제가 직접 파싱은 못 하니**, 아래 핵심 정보를
  텍스트/캡처로 함께 주시면 가장 정확합니다.
- ⚠ 이전 `선급별_FAT_OBT_프로세스_비교.pdf`처럼 **MIP(Azure RMS) 암호화 파일은 제가 열람 불가**입니다.
  암호화 자료는 캡처 이미지나 텍스트로 부탁드립니다.
- 민감정보(금액·고객명 등)는 가린 채 더미값으로 주셔도 구조 파악에 충분합니다.

## 같이 알려주시면 좋은 것
1. 컬럼(헤더) 전체 — 어떤 항목을 관리하는지
2. 상태 값 실제 표기 — 현재 6단계(대상→SCM가능→QC확정→신청→진행→완료)와 일치 여부
3. Comment 기록 방식 — 누적/날짜별/선급·내부 구분 여부
4. 선급별 차이 — DNV·ABS(또는 그 외) 컬럼·산출물·양식 차이
5. 샘플 행 2~3개 — 실제 값 형태

> 파일을 넣으신 뒤 "넣었어"라고 알려주시면 확인하고 반영하겠습니다.
