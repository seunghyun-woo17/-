혼자 수정하는 방법 가이드
색상 표기법 (공통)

# RRGGBB  →  16진수. 값이 클수록 밝음
  #ffffff = 흰색,  #000000 = 검정,  #112240 = 진한 네이비
rgba(R, G, B, 투명도)  →  투명도 0(완전투명) ~ 1(불투명)
1. 라이트 모드 밝기 조절 → css/variables.css 33~51번 줄

--body-bg: #c8d8e8;   /* 페이지 전체 배경. 숫자 낮출수록 더 어두워짐 */
--navy2:   #d4e0ee;   /* 헤더·탭 배경 */
--card:    rgba(210,225,242,0.92); /* 카드 배경. rgba 앞 숫자 낮출수록 어두워짐 */
밝기 조절 예시:

어두운 정도	--body-bg 값
지금보다 조금 더 어둡게	#b8cce0
많이 어둡게	#a0b8d0
아주 어둡게 (회색 톤)	#8aa0b8
2. 드롭다운 그룹 헤더 색 → css/components.css 55번 줄

.form-group select optgroup { background:var(--navy2); color:var(--text2); }
바꾸고 싶은 것	수정할 속성	예시 값
배경색	background:	#1a3055 , var(--navy3)
글자색	color:	var(--accent) (민트), #60a5fa (하늘), var(--text) (기본)
굵기	font-weight: 추가	700
3. 다른 색상 자주 쓰는 변수 (다크모드 기준)
변수 이름	현재 색	사용처
var(--accent)	민트 #00c9a7	강조, 카드 타이틀
var(--text)	밝은 흰 #e8edf5	본문 글자
var(--text2)	중간 회청 #8fa3be	보조 글자
var(--navy2)	진한 네이비 #112240	헤더·탭 배경
var(--card)	반투명 네이비	카드 배경
4. 색상 고르는 방법
브라우저에서 F12 → Elements 탭 클릭 후 원하는 요소 선택 → 오른쪽 CSS 패널에서 색상 박스 클릭 → 색상 피커로 직접 선택 가능합니다.
