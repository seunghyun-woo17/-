📖 BOM 엑셀 수정 · 업로드 방법 안내
BOM 엑셀("파싱용" 시트)을 수정한 뒤에는, 수정된 파일을 다시 업로드해야 시스템에 반영됩니다. 파일을 자동으로 감시하지 않으므로, 수정 후 반드시 위 [BOM 엑셀 업로드]에서 같은 파일을 다시 선택해주세요.

① 다시 업로드하면 어떻게 되나요?

  • 새로 업로드한 내용으로 BOM 데이터가 전체 교체됩니다. (구분·모델 드롭다운도 자동 갱신)
  • 이미 등록된 호선의 호선코드·BOM·발주서는 영향받지 않습니다. 호선코드는 최초 1회만 자동 부여되고 이후 보호됩니다.
  • 새로 업로드한 데이터는 앞으로 새로 등록할 호선에만 적용됩니다.

② 시트의 기본 구조 (이 틀을 유지해야 정상 인식됩니다)

열ABCDFLMN
의미 구분모델자재관리코드품명소요량 완제품코드구분모델
비고 품목 목록 (그룹별로 구분·모델은 첫 행에만 입력됨) 호선코드 앞자리를 결정하는 매핑표
  • A열(구분)·B열(모델)은 한 그룹(예: HiNAS Control)의 맨 첫 행에만 값을 입력하고, 같은 그룹의 나머지 행은 비워둡니다 (병합된 형태).
  • C열(자재관리코드) 또는 D열(품명) 중 최소 하나는 값이 있어야 품목으로 인식됩니다.
  • F열(소요량)은 반드시 숫자로 입력합니다.

③ 품목을 추가·삭제할 때

  • 기존 그룹 안에서 추가/삭제: 해당 그룹의 행 범위 안에서 행을 추가·삭제하면 됩니다. 단, 새로 끼워 넣은 행의 A·B열(구분·모델)은 비워두세요 — 값을 채우면 새로운 그룹으로 잘못 인식됩니다.
  • 완전히 새로운 모델(그룹) 추가: 표 끝(또는 그룹 사이)에 새 행을 만들고, 그 첫 행의 A열에 구분, B열에 모델명을 입력한 뒤 아래로 품목들을 나열합니다.

④ 새 모델을 추가했다면 — 완제품코드 매핑(L·M·N열)도 함께 추가하세요

L·M·N열은 "이 모델은 어떤 완제품코드를 쓰는지" 정의하는 표이며, 이 코드가 호선코드의 앞자리가 됩니다 (예: MS25-0001의 "MS"). 여기에 새 모델을 등록하지 않으면, 해당 모델로 BOM을 등록해도 호선코드가 자동 생성되지 않고 직접 입력해야 합니다.
  • 새 행에 L열 = 완제품코드, M열 = 구분, N열 = 모델명을 입력합니다.
  • 모델명은 B열(품목 목록)에 적은 이름과 정확히 일치하는 단어를 사용해야 합니다 (오탈자 주의).
  • "HiNAS Control / HiNAS SVM"처럼 모델 두 개를 합친 콤보 이름은 "HiNAS " 표기 유무나 슬래시(/) 순서가 달라도 자동으로 매칭되니 안심하고 사용하셔도 됩니다.

⑤ 체크리스트 — 업로드 전에 확인하세요

  • ☑ 시트 이름이 정확히 "파싱용" 인가요?
  • ☑ A·B열(구분·모델)이 그룹 첫 행에만 입력되어 있나요? (중간 행에 잘못 채워지지 않았는지)
  • ☑ 새 품목의 자재관리코드/품명/소요량이 모두 채워졌나요?
  • ☑ 새 모델을 추가했다면 L·M·N열에 완제품코드 매핑도 추가했나요?
  • ☑ 저장 후 같은 파일을 [BOM 엑셀 업로드]에서 다시 선택했나요?
