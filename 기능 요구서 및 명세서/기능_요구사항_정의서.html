호선 관리 (VSL) 7개 요구사항
ID 명 구분 요구사항명 요구사항 내용 중요도
VSL01 호선
관리		 호선 등록 사용자는 신조선박 또는 개조선박을 구분하여 호선명, 계약일, 납품예정일을 입력하고 등록할 수 있다. 개조선박의 경우 선사명을 추가로 입력한다. 상
VSL02 선급 입력 사용자는 호선 등록 시 선급(KR, BV, DNV, LR, ABS, 없음)을 선택하여 입력할 수 있다. 선급이 있는 호선은 FAT 관리 대상으로 자동 분류된다. 상
VSL03 호선 목록 조회 사용자는 등록된 호선 목록을 신조/개조 유형, 호선명, 계약일, 납품예정일, BOM 등록 건수, 특이사항 건수와 함께 조회할 수 있다. 상
VSL04 호선 삭제 사용자는 등록된 호선을 삭제할 수 있다. 삭제 시 연결된 BOM, 특이사항 데이터도 함께 삭제된다. 중
VSL05 특이사항 등록 사용자는 호선별로 품질·납기·SW·기타 구분에 따라 특이사항을 등록할 수 있다. BOM 대상 호선 선택 시 해당 호선의 특이사항이 자동 연동된다. 상
VSL06 특이사항 조회 및 필터 사용자는 특이사항을 전체·품질·납기·SW·기타 탭으로 필터링하여 조회할 수 있다. 각 탭은 해당 팀(품질팀, 구매팀, SW팀)의 확인 담당을 표시한다. 중
VSL07 특이사항 확인 처리 담당 팀은 특이사항에 대해 확인 처리를 할 수 있으며, 확인자명과 확인 일시가 기록된다. 중
BOM 및 안전재고 (BOM) 5개 요구사항
ID 명구분요구사항명요구사항 내용중요도
BOM01 BOM
안전재고		 BOM 세대 템플릿 적용 사용자는 1세대 BOM, 2세대 BOM 템플릿을 선택하여 호선에 일괄 적용할 수 있다. 불러온 후 수정 및 삭제가 가능하다. 상
BOM02 BOM 개별 품목 추가 사용자는 품목 코드, 품목명, 필요 수량을 입력하여 호선별 BOM에 개별 품목을 직접 추가할 수 있다. 상
BOM03 BOM 품목 삭제 사용자는 BOM에 등록된 개별 품목을 삭제할 수 있다. 중
BOM04 안전재고 현황 조회 사용자는 호선별·품목별 필요 수량 대비 현재 재고 수량을 실시간으로 조회할 수 있다. 부족 수량이 있는 경우 재고 부족 상태로 표시된다. 상
BOM05 재고 부족 알람 시스템은 호선별 필요 수량 대비 현재 재고가 부족한 경우 구매팀 확인 알람을 발생시킨다. 구매팀은 재고 부족을 확인하고 확인 여부를 기록할 수 있다. 상
PO 발행 (PO) 10개 요구사항
ID 명구분요구사항명요구사항 내용중요도
PO01 PO
발행		 PO 번호 자동생성 시스템은 [자동생성] 버튼 클릭 시 연도 기반 순번 형식(A-PO-YYNNNN, 예: A-PO-260001)으로 PO 번호를 자동 생성한다. 연도가 바뀌면 순번이 0001부터 재시작된다. 동시 접속 시 중복 번호 발생이 없어야 한다. 상
PO02 PO 등록 사용자는 PO 번호, 호선 코드, PIC(구매 담당자), 발행일, 납기일, 업체 정보, 품목 라인(품목명·코드·수량·단가·단위)을 입력하고 PO를 등록할 수 있다. 품목 라인은 복수 추가가 가능하다. 상
PO03 업체 자동완성 사용자가 Supplier Code를 입력하고 Tab 또는 Enter를 누르면 업체명과 이메일이 자동완성된다. 등록되지 않은 업체 코드 입력 시 경고 메시지를 표시한다. 상
PO04 호선 연동 선택 사용자는 PO 발행 시 Phase 0에 등록된 호선 목록에서 대상 호선을 드롭다운으로 선택할 수 있다. 신조선박과 개조선박이 그룹으로 구분되어 표시된다. 상
PO05 PO QR 코드 생성 시스템은 PO 등록 완료 시 PO 정보(PO ID, Ref No, 업체 코드, 납기일, 호선, 이메일, 품목 목록)가 인코딩된 QR 코드를 자동 생성한다. 상
PO06 PO 문서 출력 사용자는 Avikus 양식의 Purchase Order 문서를 화면에서 미리보기하고 인쇄(PDF 저장)할 수 있다. 문서에는 PO QR 코드가 우측 상단에 포함된다. 상
PO07 PO 목록 조회 사용자는 발행된 PO 목록(최근 10건)을 발행일, 납기일, 업체, 호선, 품목 건수, 상태(OPEN/PARTIAL/COMPLETE)와 함께 조회할 수 있다. 각 PO에 대해 문서 보기 및 QR 보기가 가능하다. 상
PO08 PO 상태 자동 변경 시스템은 입고 처리 완료 시 PO 수량 대비 입고 수량을 비교하여 PO 상태를 자동으로 변경한다. (전량 입고: COMPLETE, 부분 입고: PARTIAL) 상
PO09 업체 등록 사용자는 업체 코드, 업체명, 이메일, 연락처를 입력하여 업체 DB에 등록할 수 있다. 중복 업체 코드 입력 시 에러 메시지를 표시한다. 중
PO10 업체 삭제 사용자는 업체 DB에서 특정 업체를 삭제할 수 있다. 하
제품 QR 생성 (QR) 7개 요구사항
ID 명구분요구사항명요구사항 내용중요도
QR01 제품
QR
생성		 단건 QR 생성 사용자는 PO 스캔 완료 후 S/N을 직접 입력하여 단건 제품 QR을 생성할 수 있다. QR에는 PO ID, MC 코드, 품목 코드, S/N, 입고일, 업체 코드가 인코딩된다. 상
QR02 단건 QR 인쇄 사용자는 생성된 단건 QR 코드를 [QR 인쇄] 버튼으로 인쇄할 수 있다. 인쇄 화면에는 QR 이미지, S/N, 품목 코드, PO 번호가 포함된다. 상
QR03 일괄 QR 생성 (팝업 S/N 입력) 사용자는 품목별 [S/N 입력] 버튼을 클릭하면 발주 수량만큼의 S/N 입력 박스가 팝업으로 나타난다. 각 S/N을 개별 입력 후 확인하면 QR이 일괄 생성된다. 상
QR04 일괄 QR 인쇄 사용자는 일괄 생성된 QR 코드 전체를 [전체 QR 인쇄] 버튼으로 한 번에 인쇄할 수 있다. 인쇄 화면에는 각 제품의 QR 이미지, S/N, 품목 코드가 격자 형태로 표시된다. 상
QR05 현재 PO 기준 자동완성 사용자는 PO QR 스캔 완료 후 [현재 PO 기준 자동완성] 버튼 클릭 시 품목 코드와 입고일이 자동으로 입력된다. 중
QR06 QR 모드 전환 사용자는 단건 생성 모드와 일괄 생성+인쇄 모드를 라디오 버튼으로 전환할 수 있다. 중
QR07 S/N 자동 증가 시스템은 단건 QR 생성 완료 후 입력된 S/N의 끝 숫자를 자동으로 +1 증가시켜 다음 입력을 편리하게 한다. 하
입고 검수 (INC) 8개 요구사항
ID 명구분요구사항명요구사항 내용중요도
INC01 입고
검수		 PO QR 스캔 (카메라) 사용자는 HTTPS 환경에서 모바일/PC 카메라를 통해 PO QR 코드를 스캔할 수 있다. 스캔된 QR 데이터는 DB와 대조하여 유효한 PO인지 검증한다. 상
INC02 PO QR 수동 입력 사용자는 카메라 사용이 불가한 환경에서 QR 데이터를 직접 텍스트로 입력하여 스캔 처리할 수 있다. 상
INC03 제품 QR 스캔 (건별) 사용자는 PO QR 스캔 완료 후 제품 QR 코드를 건별로 스캔하여 입고 검수를 진행할 수 있다. 스캔 시 품목 코드, S/N, 수량이 실시간으로 카운팅된다. 상
INC04 중복 S/N 차단 시스템은 동일 세션에서 이미 스캔된 S/N이 재스캔될 경우 에러 메시지를 표시하고 중복 등록을 차단한다. 상
INC05 세션 간 PO 불일치 차단 시스템은 현재 세션의 PO와 다른 PO에서 발행된 제품 QR이 스캔될 경우 에러 메시지를 표시하고 스캔을 차단한다. 상
INC06 품목별 수량 진행 현황 시스템은 스캔 진행 중 품목별 발주 수량 대비 스캔 완료 수량을 실시간으로 표시한다. 전체 진행률을 퍼센트 바(Progress Bar)로 시각화한다. 상
INC07 입고 완료 처리 사용자는 [입고 완료 처리] 버튼 클릭 시 스캔 데이터를 기반으로 입고 헤더, 입고 라인, 재고를 일괄 저장하고 PO 상태를 자동 변경한다. 수량 일치·부족·초과 결과를 기록한다. 상
INC08 스캔 초기화 사용자는 [스캔 초기화] 버튼 클릭 시 현재 스캔 세션을 초기화하고 처음부터 다시 시작할 수 있다. 초기화 전 확인 팝업이 표시된다. 중
Incoming Report (RPT) 5개 요구사항
ID 명구분요구사항명요구사항 내용중요도
RPT01 Incoming
Report		 Incoming Report 자동 생성 시스템은 입고 완료 처리 시 Avikus 양식의 Incoming Report를 자동 생성한다. 문서에는 FROM(공급업체), TO(Avikus), PO Ref No, PO DATE, Incoming DATE, 품목 테이블, S/N 목록(REMARK), PIC 담당자가 포함된다. 상
RPT02 Incoming Report 인쇄 사용자는 생성된 Incoming Report를 A4 기준으로 인쇄(PDF 저장)할 수 있다. S/N 목록은 표 본문이 아닌 하단 REMARK 섹션에 품목 코드별로 정리되어 표시된다. 상
RPT03 입고 건 목록 조회 사용자는 Phase 4에서 입고 건 목록을 최신순으로 조회할 수 있다. 각 입고 건에는 PO 번호, 입고일, 수량(실입고/발주), 상태(COMPLETE/SHORT/OVER), 서류 첨부 현황이 표시된다. 상
RPT04 서류 첨부 현황 표시 시스템은 각 입고 건에 대해 Incoming Report, 검사성적서, COC, 거래명세서의 첨부 여부를 색상 배지(● 첨부됨 / ○ 미등록)로 표시한다. 상
RPT05 서류 보기 사용자는 첨부 완료된 서류 배지를 클릭하여 해당 파일(PDF/이미지)을 새 창에서 확인할 수 있다. 중
서류 첨부 관리 (DOC) 5개 요구사항
ID 명구분요구사항명요구사항 내용중요도
DOC01 서류
첨부
관리		 서류 첨부 모달 표시 시스템은 입고 완료 처리 후 1.5초 뒤 자동으로 서류 첨부 모달을 표시한다. 모달에는 검사성적서·COC·거래명세서 3개 섹션이 포함된다. 상
DOC02 검사성적서 첨부 사용자는 PDF/JPG/PNG 형식의 검사성적서 파일을 첨부할 수 있다. 성적서 1장을 첨부하면 해당 입고 건의 모든 S/N 재고에 자동으로 연결된다. (1장 → N개 제품 일괄 연결) 상
DOC03 COC 첨부 사용자는 PDF/JPG/PNG 형식의 COC(Certificate of Conformance) 파일을 첨부할 수 있다. COC는 성적서와 독립적으로 관리된다. 상
DOC04 거래명세서 첨부 사용자는 PDF/JPG/PNG 형식의 거래명세서 파일을 첨부할 수 있다. 거래명세서는 성적서, COC와 독립적으로 관리된다. 상
DOC05 서류 추가 첨부 및 수정 사용자는 입고 완료 시점 이후에도 Phase 4에서 [서류 첨부/수정] 버튼을 통해 언제든지 서류를 추가하거나 수정할 수 있다. 이미 첨부된 서류는 파일명이 표시된다. 상
재고 현황 (INV) 6개 요구사항
ID 명구분요구사항명요구사항 내용중요도
INV01 재고
현황		 재고 현황 전체 조회 사용자는 관리 코드(MC), 품목 코드, S/N, 발주서 번호, 공급업체, 입고일, 배정 호선, 보관 위치, 성적서 첨부 여부, 재고 상태를 포함한 전체 재고 목록을 조회할 수 있다. 상
INV02 품목별 그룹 조회 사용자는 품목 코드별로 그룹화된 요약 카드(총 수량, 재고, 출고, 대여)를 1단계로 조회하고, 카드 클릭 시 해당 품목의 S/N 목록을 2단계로 확인할 수 있다. 2,000개 이상의 S/N을 효율적으로 탐색하기 위한 구조이다. 상
INV03 재고 상태 표시 시스템은 각 재고의 상태를 재고(IN_STOCK)·출고(SHIPPED)·대여중(RENTED)·검사요청(INSPECTION_REQUESTED) 배지로 구분하여 표시한다. 상태별 색상이 다르게 적용된다. 상
INV04 성적서 첨부 여부 표시 시스템은 각 재고 행에 검사성적서 첨부 여부를 '첨부됨(녹색)' 또는 '미등록(주황)'으로 표시한다. 중
INV05 수기 재고 등록 관리자는 PIN 인증(4자리) 후 Phase 0~3 프로세스 없이 품목 코드, S/N, PO 번호, 업체, 입고일, 보관 위치를 직접 입력하여 재고를 수동 등록할 수 있다. 연속 등록 시 S/N이 자동 증가된다. 중
INV06 통계 카드 표시 시스템은 Phase 5 상단에 발행 PO 수, 재고 품목(S/N) 수, 완료 입고 수, 미완료 PO 수를 요약 카드로 표시한다. 하
출고·대여·검사요청 (OUT) 7개 요구사항
ID 명구분요구사항명요구사항 내용중요도
OUT01 출고
대여
검사요청		 재고 다중 선택 사용자는 재고 현황 테이블에서 체크박스로 복수의 제품을 선택할 수 있다. 전체 선택/해제 기능이 제공된다. 이미 출고·대여된 제품의 체크박스는 비활성화된다. 상
OUT02 출고 처리 사용자는 선택된 재고에 대해 [출고] 버튼 클릭 후 배정 호선과 메모를 입력하여 출고 처리할 수 있다. 처리 후 재고 상태가 SHIPPED로 변경되고 출고 이력이 기록된다. 상
OUT03 대여 처리 사용자는 선택된 재고에 대해 [대여] 버튼 클릭 후 배정 호선과 메모를 입력하여 대여 처리할 수 있다. 처리 후 재고 상태가 RENTED로 변경되고 대여 이력이 기록된다. 상
OUT04 검사요청 처리 사용자는 선택된 재고에 대해 [검사요청] 버튼 클릭 후 메모를 입력하여 검사요청 처리할 수 있다. 처리 후 재고 상태가 INSPECTION_REQUESTED로 변경된다. 상
OUT05 출고·대여 이력 조회 사용자는 출고·대여·검사요청 처리된 이력을 S/N, 액션 종류, 배정 호선, 처리일, 메모와 함께 조회할 수 있다. 중
OUT06 반납 처리 사용자는 대여 중인 제품을 반납 처리하여 재고 상태를 IN_STOCK으로 복원할 수 있다. 반납 이력이 기록된다. 중
OUT07 처리 확인 팝업 시스템은 출고·대여·검사요청 처리 시 선택된 제품 S/N 목록을 확인 팝업으로 표시한다. 사용자가 최종 확인 후 처리가 완료된다. 중
FAT 관리 (FAT) 6개 요구사항
ID 명구분요구사항명요구사항 내용중요도
FAT01 FAT
관리		 FAT 대상 자동 추출 시스템은 선급이 입력된 호선에 배정된 재고 중 FAT 미완료 제품을 자동으로 추출하여 FAT 관리 목록에 표시한다. 상
FAT02 출고 예정일 입력 구매팀은 FAT 대상 제품별로 출고 예정일을 입력할 수 있다. 입력된 출고 예정일을 기준으로 FAT 신청 기한이 계산된다. 상
FAT03 FAT 기한 임박 알림 시스템은 프로그램 접속 시 출고 예정일까지 30일 이내인 FAT 미완료 건을 자동으로 확인하여 팝업으로 알림을 표시한다. 서버 전환 후에는 매주 월요일 구매팀·품질팀에 이메일로 자동 발송한다. 상
FAT04 FAT 완료 처리 사용자는 FAT 진행 완료 후 [FAT 완료] 버튼을 클릭하여 완료 처리할 수 있다. 완료 일시가 자동 기록된다. 상
FAT05 FAT 결과 문서 첨부 사용자는 FAT 완료 후 생성된 결과 문서(FAT Procedure, Onboard Test Procedure 등)를 PDF/이미지 형식으로 첨부할 수 있다. 상
FAT06 FAT 이력 조회 사용자는 호선별·제품별 FAT 신청 및 완료 이력을 조회할 수 있다. 완료된 건은 완료 일시와 담당자가 표시된다. 중
시스템 공통 (SYS) 8개 요구사항
ID 명구분요구사항명요구사항 내용중요도
SYS01 시스템
공통		 ERP 탭 구조 시스템은 단일 웹 주소에서 구매·자재관리, 출고·대여·검사요청, FAT 관리 탭을 제공하며, 모든 탭이 동일한 DB를 공유한다. 상
SYS02 다크/라이트 모드 사용자는 헤더의 모드 전환 버튼을 통해 다크 모드와 라이트 모드를 전환할 수 있다. 선택된 모드는 다음 접속 시에도 유지된다. 하
SYS03 알림 토스트 시스템은 주요 처리 완료, 경고, 오류 발생 시 화면 우하단에 토스트 메시지를 3초간 표시한다. 성공(녹색), 경고(주황), 오류(빨강)로 색상을 구분한다. 중
SYS04 DB 전체 초기화 관리자는 [DB 전체 초기화] 버튼 클릭 후 확인 팝업을 통해 전체 데이터를 초기화할 수 있다. 초기화 후 복구 불가 안내가 포함된다. 하
SYS05 관리자 PIN 인증 시스템은 수기 재고 등록 등 관리자 전용 기능 접근 시 4자리 PIN 입력을 요구한다. PIN 인증 후 해당 세션에서는 재인증 없이 사용 가능하다. 중
SYS06 데이터 유지 시스템은 브라우저 새로고침 후에도 모든 데이터(호선, PO, 재고, 입고 이력 등)가 유지되어야 한다. 서버 전환 후 PostgreSQL DB에서 영구 저장된다. 상
SYS07 다중 PC 동시 접속 서버 전환 후, 여러 PC에서 동시에 접속하여 데이터를 공유하고 실시간으로 반영받을 수 있어야 한다. 최소 5명 동시 접속을 지원한다. 상
SYS08 간이 스캔 시뮬레이터 시스템은 개발·테스트 환경에서 실제 QR 스캐너 없이 버튼 클릭만으로 PO QR 스캔 및 제품 QR 단건/일괄 스캔을 시뮬레이션할 수 있다. 서버 전환 전 삭제 예정인 개발 전용 기능이다. 하
