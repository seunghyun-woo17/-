📋 사용 설명서

🗓 주간 관리
자동 새 주 시작매주 월요일 앱을 열면 자동으로 새로운 주가 시작돼요.
미완료 이월저번 주에 완료하지 못한 태스크는 이번 주로 자동 이월되며 주황 테두리와 "이월" 태그로 표시돼요.
이월 해제이월 항목이 있을 때 상단 "이월 해제" 버튼을 누르면 일반 태스크로 전환돼요.
주간 메모이번 주 목표나 중요 사항을 한 줄로 기록할 수 있어요. 이전 기록에도 남아요.
➕ 태스크 추가
AI 자동 파싱Slack 메시지를 그대로 붙여넣으면 AI가 요청자·할 일·마감일을 자동으로 추출해요. (API 키 필요)
직접 입력요청자·할 일·마감일·우선순위를 직접 입력할 수 있어요.
우선순위높음(빨강) / 보통(노랑) / 낮음(초록) 세 단계로 설정할 수 있어요.
✏️ 태스크 관리
완료 체크태스크 왼쪽 체크박스를 클릭하면 완료 처리돼요.
수정태스크에 마우스를 올리면 나타나는 ✏️ 버튼을 클릭하면 요청자·할 일·마감일·우선순위를 수정할 수 있어요.
메모▾ 버튼을 클릭하면 태스크별 메모창이 열려요. 완료 방법, 다음에 할 것, 개선 사항 등을 자유롭게 기록할 수 있어요. 파란 점이 표시되면 메모가 있다는 뜻이에요.
삭제태스크에 마우스를 올리면 나타나는 ✕ 버튼으로 삭제할 수 있어요.
📊 보기 및 정렬
완료율상단 프로그레스 바에서 이번 주 완료율을 한눈에 확인할 수 있어요.
필터전체 / 진행중 / 완료 탭으로 태스크를 필터링할 수 있어요.
정렬마감일 순 또는 우선순위 순으로 정렬할 수 있어요. 마감 초과 항목은 항상 상단에 표시돼요.
마감일 표시오늘 마감 / D-숫자 / D+숫자 초과로 표시돼요. 마감일이 지나야 초과로 표시돼요.
🔍 검색
전체 검색검색창에 키워드를 입력하면 전체 주 기록에서 태스크를 검색해요. 태스크 내용, 요청자, 메모 내용까지 검색돼요.
하이라이트검색 결과에서 키워드가 보라색으로 강조 표시돼요.
📁 이전 기록
주별 아카이브상단 "이전 기록" 탭에서 지난 주들의 태스크를 확인할 수 있어요.
완료율 확인각 주별 완료율과 태스크 수를 한눈에 볼 수 있어요.
메모 확인해당 주에 작성한 주간 메모와 태스크별 메모도 함께 확인할 수 있어요.
⚙️ 기타
제목 수정좌측 상단 제목을 클릭하면 원하는 이름으로 바꿀 수 있어요.
데이터 저장모든 데이터는 이 브라우저에만 저장돼요. 파일을 공유해도 각자의 데이터는 독립적으로 유지돼요.
AI 파싱 설정우측 상단 "API 설정"에서 Anthropic API 키를 입력하면 AI 자동 파싱 기능을 사용할 수 있어요. console.anthropic.com에서 발급 가능해요.
